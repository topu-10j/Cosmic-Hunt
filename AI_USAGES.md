# Use of Super Intelligence (SI)

**Cosmic Hunt · Team Sparks · NASA Space Apps Challenge 2026**

## Ideation or Brainstorming

We used ChatGPT to brainstorm ways for players to explore the game, investigate infrared clues, and follow the Planet X mission.

## Building SI/ML Into the Project

The **Ask AI** panel uses the Anthropic Claude API (`claude-haiku-5-5`) to answer questions about astronomy and the game when a player supplies an Anthropic API key. The panel uses built-in answers by default and falls back to them if the API request fails. [Ask AI source](./js/ask-ai.js)

## Coding, Debugging, or Troubleshooting

- **Anthropic Claude.** We used Claude to understand unfamiliar code, troubleshoot errors, and generate source code for the game.
- **OpenAI ChatGPT** helped format HTML, CSS and JavaScript and fix syntax, audio file matching and planet-image filtering. It also drafted a React/Zustand state store and a 15-entry JavaScript exoplanet dataset for early prototypes. [NASA Explorer source](./js/nasa-explorer.js)

## Writing, Editing, or Translation

We used ChatGPT to review the README setup instructions and draft the English demo narration script and scene directions. [README](./README.md)

## Promotional poster drafts

We used generative image editing to create draft poster variants and adjust the team photo composition. The image tool and the inclusion of these drafts in the submission are unconfirmed.
