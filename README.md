## 🌍 About the Project

**Cosmic Hunt** is a free, browser-based 3D space exploration game developed by **Team Sparks** for the **NASA Space Apps Challenge 2026**.

Our mission is to make space science accessible, interactive, and exciting for everyone.

Designed for students, teachers, and curious beginners, Cosmic Hunt combines immersive 3D environments, real NASA resources, infrared-inspired scanning, and mystery-solving gameplay.

With English and Bengali-friendly text, users can explore the universe without special equipment or prior astronomical knowledge.

> **Our Vision:** Turning curiosity about space into an unforgettable learning adventure.

## 🎯 The Challenge & Our Solution

Space science can feel complicated and inaccessible to beginners. Traditional learning materials often lack interactive experiences.

**Cosmic Hunt changes that.**

Instead of simply reading about space, players can explore celestial objects, examine astronomical information, investigate infrared clues, and complete an exciting mission to find a mysterious Planet X.

We combine **Education + Exploration + Interactive Gameplay** in one accessible platform.

## ✨ Key Features

- 🪐 **Interactive 3D Universe** — Rotate, zoom, and explore planets and celestial objects.
- 🔭 **Exoplanet Atlas** — Discover Proxima Centauri b, TRAPPIST-1e, Kepler-452b, and more.
- 🌍 **Multiple Cosmic Views** — Explore Earth, satellites, the Milky Way, and distant galaxies.
- 🌌 **Deep Space Exploration** — Visualize black holes, wormholes, supernovae, pulsars, and other cosmic phenomena.
- 🔎 **Infrared Scanner** — Examine simulated infrared signatures inspired by NASA's SPHEREx mission.
- 📊 **Spectrum Graph & Data Clue Box** — Analyze spectral clues to identify the hidden target.
- 🛰️ **NASA Explorer** — Access NASA imagery, maps, astronomical media, and educational information.
- 🤖 **Ask AI Assistant** — Ask space-related questions using built-in answers or optional AI integration.
- 🎮 **Find Planet X Mission** — Solve an interactive mystery using exploration and scientific clues.
- 🌐 **Accessible Learning** — Browser-based experience with English and Bengali-friendly typography.

## 🛰️ NASA APIs & Scientific Resources

Cosmic Hunt integrates or references the following NASA services:

| API / Dataset | Purpose |
|---|---|
| [NASA GIBS](https://gibs.earthdata.nasa.gov/) | Earth imagery and temperature layers |
| [NASA Mars Trek](https://trek.nasa.gov/mars/) | Mars surface maps |
| [NASA Moon Trek](https://trek.nasa.gov/moon/) | Lunar surface imagery |
| [NASA Image & Video Library](https://images.nasa.gov/) | Astronomy images, audio, and information |
| [NASA APOD](https://apod.nasa.gov/apod/) | Astronomy Picture of the Day |
| [NASA Worldview](https://worldview.earthdata.nasa.gov/) | External Earth observation explorer |
| [NASA Planetary Fact Sheet](https://nssdc.gsfc.nasa.gov/planetary/factsheet/) | Reference planetary information |
| [NASA SPHEREx](https://science.nasa.gov/mission/spherex/) | Scientific inspiration for infrared exploration |

**Additional Resources:** NASA Exoplanet Archive (reference), Three.js, Google Fonts, and optional Anthropic AI.

NASA services are accessed where supported; availability may depend on internet connectivity and API limits. Some planetary values are stored locally rather than fetched live.

## 🚀 Run Locally

Clone the repository:

```bash
git clone https://github.com/topu-10j/Cosmic-Hunt.git
cd Cosmic-Hunt
```

Open the project in **VS Code** and run `index.html` using the **Live Server** extension.

Alternatively, start a local server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

No installation or complex setup is required.

## 🌟 Our Impact

Cosmic Hunt encourages curiosity, scientific thinking, and independent exploration.

**You don't need to be an astronaut to begin exploring the universe.**

## 📌 Scientific & Security Notes

Planet X is a **fictional educational game objective**, not a verified astronomical discovery. Infrared scanning and spectral clues are educational simulations inspired by SPHEREx, not live telescope measurements.

This is an independent student project developed for NASA Space Apps Challenge 2026 and is not an official NASA product.

Optional AI functionality requires a user-provided API key. Never publish private API keys in the repository or frontend source code.
